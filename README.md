## 🚀 Featured Projects

### [ Dineflow](https://github.com/Reddykesava60/OrderFlow)

A production-oriented, multi-tenant cafe and restaurant operations platform that centralizes QR ordering, kitchen displays, inventory, payments, and financial reconciliation. It addresses the common operational problems of lost paper tickets, overselling, delayed settlement, and disconnected outlet workflows.

**Key technologies:** Django 5, Django Channels, PostgreSQL, Redis Pub/Sub, WebSockets, Razorpay, Docker, Tailwind CSS

### [RecoveryAI — FedEx DCA Intelligence Platform](https://github.com/Reddykesava60/fedex_dca_system_)

An enterprise-focused debt collection agency management platform that brings case prioritization, agency coordination, AI-driven insights, and operational dashboards into a unified workflow. The project replaces fragmented spreadsheets and manual tracking with a modern, data-led management experience.

**Key technologies:** Next.js, TypeScript, React, SQLite/Drizzle, Firebase, Tailwind CSS, AI integrations

### [WikiLite](https://github.com/Reddykesava60/WikiLite)

A lightweight encyclopedia application that enables users to create, search, edit, and discover Markdown-based knowledge entries. It demonstrates clean Django routing, content processing, search behavior, and server-rendered UI patterns.

**Key technologies:** Python, Django, Markdown2, HTML, CSS

### [Python Console Banking System](https://github.com/Reddykesava60/BANKING-SYSTEM)

A terminal-based banking application that demonstrates reliable account management and transaction handling through object-oriented design and persistent JSON storage. It covers deposits, withdrawals, balance checks, validation, and overdraft prevention.

**Key technologies:** Python, Object-Oriented Programming, JSON file persistence
